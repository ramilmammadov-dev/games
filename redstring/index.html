Red String Support

Red String is a free detective word game. Sort clue cards into hidden case files, stamp the topics and name the culprit.

How to play

  • Tap the deck to draw a clue card, then tap the case file it belongs to. Right clues are pinned with red string.
  • A wrong file costs a move. After two right clues the topic is stamped on the file.
  • Clues that fit no file are red herrings. Drop them in the bin for a bonus.
  • File every clue, then pick the suspect who ties all the files together.
